# Assignment 90 – Master Autonomous Heterogeneous Engine Capstone II

## Overview & Architectural Critique
The ultimate synthesis of cutting-edge Vulkan 1.4 graphics engineering. **Assignment 90** builds a fully autonomous, heterogeneous mega-engine combining 64-bit BDA raw pointer geometry, dynamic multi-light PBR shading, Synchronization2 pipeline hazard barriers, and Dynamic Rendering with zero CPU descriptor pool contention.

## Key Vulkan 1.4 Concepts
- **Autonomous Master Architecture**: Complete synthesis of Vulkan 1.4 core features.
- **64-bit Buffer Device Address (BDA)**: Raw pointer dereferencing in vertex/fragment shaders.
- **Synchronization2 & Dynamic Rendering**: Monolithic multi-light dynamic forward pass.

## Acceptance Criteria
- [x] Integrate 64-bit BDA descriptorless geometry with Dynamic Rendering.
- [x] Multi-light forward dynamic PBR shading with rotating orbital structures.
- [x] 0 validation layer errors.
